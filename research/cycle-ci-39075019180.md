# Improvement Cycle CI-39075019180

## Problem
GitHub Actions Tests run 39075019180 failed on commit 38c181f
("fix(code_synth): restore working loader after accidental PLACEHOLDER …").
Core unit tests (excl. code_synth) failed:
`test_binary_search_routes_to_code_not_research` expected `def binary_search`
but got a stub `def implement_binary_search_on_a_sorted_list`.

## Root cause
Slim `code_synth.py` loader uses importlib to load `code_synth_p*.py` packs.
Several early packs (p1, p1b, …) do `from code_synth import Template, _TWO`.
The restored slim module did not define `_TWO`, so those packs failed to import
and classic templates (including `binary_search`) were missing. Agents fell back
to a NotImplemented stub + web hedge.

## Fix
Add the missing private constant the packs expect:

```python
_TWO = r"(two|2|a pair of)"
```

Also add a `TEMPLATES = get_templates()` alias so `tests/unit/test_code_synth.py`
can import it.

  → 159 passed, 1 skipped (was 1 failed).
- Probe: `implement binary search on a sorted list` → `def binary_search` + Verified.

## Result
Core unit tests pass. CI failure on binary_search routing resolved.
